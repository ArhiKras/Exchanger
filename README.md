## 📋 Описание

Traveler Wallet Bot — это не просто конвертер валют, а полноценный миникошелёк для путешественника. Бот помогает:

- 🌍 Создавать путешествия между странами с разными валютами
- 💱 Отслеживать актуальные курсы валют через реальный API
- 💰 Вести учёт расходов в валюте страны пребывания
- 📊 Просматривать историю всех трат
- ✈️ Управлять несколькими путешествиями одновременно

## ✨ Основные возможности

### Создание путешествия
- Выбор страны отправления и назначения
- Автоматическое определение валют
- Получение актуального курса от API
- Возможность ввести свой курс (например, от местного обменника)
- Конвертация начальной суммы через API

### Учёт расходов
- Любое число в сообщении = расход в валюте страны пребывания
- Автоматическая конвертация в домашнюю валюту
- Подтверждение перед добавлением расхода
- Отслеживание баланса в обеих валютах

### Управление
- Полноценное inline-меню для навигации
- Несколько путешествий с переключением между ними
- История всех расходов с датами
- Возможность изменить курс обмена
- Удаление путешествий

## 🚀 Установка и запуск

### Требования
- Python 3.10+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- API Key от [exchangerate.host](https://exchangerate.host/)

📖 **Подробная инструкция по получению токенов:** [SETUP_GUIDE.md](docs/SETUP_GUIDE.md)

### Шаги установки

1. **Клонируйте репозиторий или скачайте файлы**

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Создайте файл `.env` на основе `docs/env.example`:**
```bash
cp docs/env.example .env
```

4. **Отредактируйте файл `.env` и добавьте свои токены:**
```env
BOT_TOKEN=ваш_токен_telegram_бота
CURRENCY_API_KEY=ваш_ключ_api_exchangerate_host
```

5. **Запустите бота:**

```bash
python run.py
```

### Команды бота

- `/start` — Запуск бота и показ главного меню
- `/newtrip` — Создать новое путешествие
- `/switch` — Переключиться между путешествиями
- `/balance` — Показать текущий баланс
- `/history` — История расходов
- `/setrate` — Изменить курс обмена

### Главное меню

Бот предоставляет удобное inline-меню с кнопками:

- 🌍 **Создать новое путешествие** — начать новое путешествие
- ✈️ **Мои путешествия** — просмотр и управление путешествиями
- 💰 **Баланс** — текущий баланс активного путешествия
- 📊 **История расходов** — все траты по активному путешествию
- 💱 **Изменить курс** — обновить курс обмена

### Пример использования

1. **Создание путешествия:**
   - Нажмите "Создать новое путешествие"
   - Введите страну отправления (например, "Россия")
   - Введите страну назначения (например, "Турция")
   - Подтвердите курс от API или введите свой
   - Укажите начальную сумму в рублях

2. **Учёт расходов:**
   - Просто отправьте боту число: `500`
   - Бот покажет: "500 TRY = 2850 RUB"
   - Нажмите "✅ Да" для подтверждения
   - Баланс обновится автоматически

3. **Просмотр баланса:**
   - Нажмите "💰 Баланс"
   - Увидите остаток в обеих валютах

## 🗄️ База данных

Бот использует SQLite для локального хранения данных. База создаётся автоматически при первом запуске.

### Таблицы:
- `users` — пользователи бота
- `trips` — путешествия пользователей
- `expenses` — расходы по каждому путешествию

## 🌐 API Integration

Бот работает исключительно с **api.exchangerate.host**:

- **Endpoint:** `http://api.exchangerate.host/convert`
- **Параметры:** `access_key`, `from`, `to`, `amount`
- **Функции:** Получение курсов, конвертация валют

Все запросы к API выполняются через модуль `services/utils.py`, который использует функции из `services/api_client.py`.

Бот поддерживает 35+ стран и их валюты, включая:

- 🇷🇺 Россия (RUB)
- 🇺🇸 США (USD)
- 🇨🇳 Китай (CNY)
- 🇯🇵 Япония (JPY)
- 🇬🇧 Великобритания (GBP)
- 🇪🇺 Европа (EUR)

## 🛠️ Технологии

- **Python 3.10+**
- **aiogram 3.13.1** — асинхронная библиотека для Telegram Bot API
- **SQLite3** — база данных для хранения данных
- **requests** — HTTP-запросы к API
- **python-dotenv** — управление переменными окружения

## 🔒 Безопасность

- Все чувствительные данные (токены, API ключи) хранятся в `.env` файле
- Файл `.env` добавлен в `.gitignore` (не попадает в репозиторий)
- Каждый пользователь имеет изолированный набор путешествий
- Все данные хранятся локально в SQLite

## 📝 Обработка ошибок

Бот корректно обрабатывает:

- ❌ Ошибки API (недоступность, неверный ключ)
- ❌ Неверный ввод пользователя (не число, отрицательные значения)
- ❌ Отсутствие валюты для страны
- ❌ Недостаточный баланс для расхода
- ❌ Отсутствие активного путешествия

Все ошибки сопровождаются понятными сообщениями для пользователя.
