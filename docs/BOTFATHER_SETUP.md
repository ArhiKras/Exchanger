# Команды для настройки бота в @BotFather

## Установка команд

Отправьте @BotFather команду `/setcommands`, выберите своего бота и вставьте следующий текст:

```
start - Запустить бота
newtrip - Создать новое путешествие
switch - Переключить путешествие
balance - Показать баланс
history - История расходов
setrate - Изменить курс обмена
```

## Описание бота

Отправьте `/setdescription` и вставьте:

```
🌍 Твой личный кошелёк для путешествий!

Управляй расходами в разных странах, конвертируй валюты по актуальным курсам и веди учёт своих путешествий.

✨ Основные возможности:
• Создание путешествий с автоматической конвертацией
• Учёт расходов в валюте страны пребывания
• История всех трат с датами
• Управление несколькими путешествиями
• Актуальные курсы валют через API

Просто отправь число — и бот учтёт расход! 💰
```

## Краткое описание

Отправьте `/setabouttext` и вставьте:

```
🌍 Миникошелёк для путешественника

Управляй расходами, конвертируй валюты и веди учёт путешествий. Актуальные курсы через API exchangerate.host.
```

## Дополнительные настройки

### Inline Mode (опционально)
Если хотите включить inline режим:
```
/setinline
```
Placeholder текст: "Введите сумму расхода..."

### Режим групп (опционально)
Если хотите разрешить добавление в группы:
```
/setjoingroups
Enable
```

### Privacy Mode
Для корректной работы в группах:
```
/setprivacy
Disable
```

💡 **Совет:** После настройки всех параметров проверьте, как выглядит ваш бот в поиске Telegram!
