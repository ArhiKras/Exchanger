# 🔑 Инструкция по получению токенов

## 1. Telegram Bot Token

### Шаги:

1. **Откройте Telegram** и найдите бота [@BotFather](https://t.me/BotFather)

2. **Отправьте команду** `/newbot`

3. **Введите имя бота** (например: "My Traveler Wallet")

4. **Введите username бота** (должен заканчиваться на `bot`, например: `my_traveler_wallet_bot`)

5. **Получите токен** — BotFather отправит вам сообщение с токеном вида:
   ```
   123456789:ABCdefGHIjklMNOpqrsTUVwxyz1234567890
   ```

6. **Скопируйте токен** и вставьте в файл `.env`:
   ```env
   BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz1234567890
   ```

### Дополнительные настройки (опционально):

- `/setdescription` — установить описание бота
- `/setabouttext` — установить текст "О боте"
- `/setuserpic` — установить аватар бота
- `/setcommands` — установить список команд

#### Рекомендуемые команды для бота:
```
start - Запустить бота
newtrip - Создать новое путешествие
switch - Переключить путешествие
balance - Показать баланс
history - История расходов
setrate - Изменить курс обмена
```

## 2. Exchange Rate API Key

### Вариант 1: ExchangeRate.host (Рекомендуемый)

1. **Перейдите на сайт** [https://exchangerate.host/](https://exchangerate.host/)

2. **Зарегистрируйтесь:**
   - Нажмите "Sign Up" или "Get Free API Key"
   - Заполните форму регистрации
   - Подтвердите email

3. **Получите API ключ:**
   - После входа в личный кабинет найдите раздел "API Key"
   - Скопируйте ваш ключ

4. **Вставьте ключ в `.env`:**
   ```env
   CURRENCY_API_KEY=ваш_ключ_api
   ```

## 3. Проверка токенов

После получения обоих токенов:

1. **Создайте файл `.env`:**
   ```bash
   cp docs/env.example .env
   ```

2. **Отредактируйте `.env` и вставьте токены:**
   ```env
   BOT_TOKEN=ваш_telegram_токен
   CURRENCY_API_KEY=ваш_api_ключ
   ```

3. **Проверьте подключение к API:**
   ```bash
   python test_api.py
   ```

4. **Запустите бота:**
   ```bash
   python run.py
   ```

## 🔒 Безопасность

⚠️ **ВАЖНО:**

- **Никогда** не публикуйте файл `.env` в открытый доступ
- **Не** коммитьте `.env` в Git (уже добавлен в `.gitignore`)
- **Не** делитесь токенами с третьими лицами
- Если токен скомпрометирован:
  - Для Telegram: используйте `/revoke` в @BotFather
  - Для API: сгенерируйте новый ключ в личном кабинете

## ❓ Часто задаваемые вопросы

### Q: Бот не отвечает на сообщения
**A:** Проверьте:
1. Правильность токена в `.env`
2. Запущен ли скрипт `run.py`
3. Нет ли ошибок в консоли

### Q: API возвращает ошибку 401
**A:** Неверный API ключ. Проверьте:
1. Правильность ключа в `.env`
2. Активна ли ваша подписка на exchangerate.host
3. Не превышен ли лимит запросов

### Q: API возвращает ошибку 429
**A:** Превышен лимит запросов. Варианты:
1. Подождите до следующего месяца (бесплатный план)
2. Обновите подписку на платный план

### Q: Бот показывает "Не удалось получить курс обмена"
**A:** Проблема с API. Проверьте:
1. Интернет-соединение
2. Работоспособность API через `test_api.py`
3. Правильность валютных кодов (USD, EUR, RUB и т.д.)
