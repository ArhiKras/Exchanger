# 📝 Быстрая шпаргалка

## 🚀 Первый запуск

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Создайте .env файл
cp docs/env.example .env

# 3. Добавьте токены в .env
# BOT_TOKEN=ваш_токен
# CURRENCY_API_KEY=ваш_ключ

# 4. Проверьте API
python test_api.py

# 5. Запустите бота
python run.py
# или на Windows:
start_bot.bat
```

## 💬 Основные команды

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота и показать меню |
| `/newtrip` | Создать новое путешествие |
| `/switch` | Переключиться между путешествиями |
| `/balance` | Показать текущий баланс |
| `/history` | История расходов |
| `/setrate` | Изменить курс обмена |

## 📱 Как пользоваться

### Создать путешествие
1. Нажми "🌍 Создать новое путешествие"
2. Введи страну отправления (например: Россия)
3. Введи страну назначения (например: Турция)
4. Подтверди курс или введи свой
5. Укажи начальную сумму

### Добавить расход
Просто отправь боту число:
```
500
```
Бот спросит подтверждение и вычтет из баланса.

### Посмотреть баланс
Нажми "💰 Баланс" или отправь `/balance`

### Изменить курс
Нажми "💱 Изменить курс" и введи новый курс

## 🐛 Решение проблем

### Бот не запускается
```bash
# Проверьте .env файл
cat .env

# Проверьте зависимости
pip install -r requirements.txt

# Попробуйте запустить напрямую
python run.py
```

### Ошибка API
- Проверьте правильность `CURRENCY_API_KEY`
- Убедитесь, что не превышен лимит запросов
- Проверьте интернет-соединение

### База данных
База создаётся автоматически при первом запуске в файле `traveler_wallet.db`

## 💡 Советы

1. **Несколько путешествий**: Создавайте отдельное путешествие для каждой поездки
2. **Свой курс**: Используйте курс местного обменника для точности
3. **История**: Все расходы сохраняются с датами
4. **Переключение**: Легко переключайтесь между активными путешествиями
5. **Баланс**: Показывается в обеих валютах
